# УВП-280 Монитор

Программа для Windows: просмотр и (в следующих версиях) настройка вычислителей УВП-280.01 по Modbus TCP.
Не требует установки — один файл `UVP280Monitor.exe`.

## Что умеет (версия 0.1 — только чтение)
- Список приборов (добавить / изменить / удалить, импорт и экспорт), сводка по всем приборам.
- Главный экран: время прибора и расхождение с ПК, состояние NTP-клиента, ошибки по трубопроводам.
- Трубопроводы: давление, температура, расходы, накопленные итоги, прошлый час и сутки, настройки из карты параметров.
- Датчики (логические входы): значения, единицы, источники, состояние.
- Учёт нефти (СИКН, БИК, линии, итоги часового/двухчасового, сменного и суточного периодов, КМХ, пробоотборник) — только на приборах, где он настроен.
- Архивы: запрос отчёта за период (в том числе двухчасовой), просмотр, копирование, CSV.
- Единицы измерения переключаются (давление по умолчанию — МПа).
- Порядок байт и адресация определяются автоматически по контрольным константам прибора.

## Запуск
Скачайте `UVP280Monitor.exe` из раздела **Actions → Артефакты** (или **Releases**) и запустите.
Окно открывается в Microsoft Edge в режиме приложения (Windows 11: уже установлен).
Список приборов хранится в `%APPDATA%\UVP280Monitor\devices.json`.

## Разработка
```
python -m uvpmon                  # запуск (нужен только Python 3.8+, без библиотек)
python tools/uvp_emulator.py --port 1502 --oil      # эмулятор прибора для проверки
python -m unittest discover -s tests
```
Сборка `.exe` выполняется автоматически GitHub Actions (`.github/workflows/build.yml`).

`tools/uvp_probe.ps1` — диагностический скрипт (только чтение) для проверки нового прибора.
